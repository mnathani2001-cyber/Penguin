# A heartfelt apology

A responsive, single-page apology website built with plain HTML, CSS, and JavaScript.

## Run locally

From this directory:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Personalize it

Edit the letter and headings in `index.html`. The page intentionally avoids names so it works immediately, but adding her name and a specific acknowledgment will make the apology feel much more personal.
